# ThreeDee

Simple 3D model viewer that only uses math, built with rust and raylib

- Use the `W`/`A`/`S`/`D`/`Q`/`E` keys to rotate the shape in view
- Use `X`/`Z` keys to change the Z translation
- Use `1`/`2`/`3` keys to switch between showing a cube / pyramid / N-sided shape

Controls for the N-sided shape:

- Use `-`/`+` keys to change number of sides
- Use `[`/`]` keys to change the radius
- Use `;`/`'` keys to change the height
